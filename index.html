A language that puts
the verb last.

BOREALIS is an agglutinative, subject–object–verb language built on the shared grammatical logic of the Eurasian steppe and taiga — Finnish, Estonian, Hungarian, Turkish, Kazakh, Mongolian, Korean, Japanese. Conditions and loops aren't keywords you write in front of an expression. They're suffixes you attach to the end of it.

How it reads

Nothing is renamed for its own sake. Every BOREALIS line becomes one recognizable Python line — the difference is where the grammar sits.

source.bor
weather = "rainy"

weather == "rainy"if:
    "Take umbrella" print.
otherwise:
    "Stay home" print.

counter <= 5while:
    counter print.
    counter = counter + 1
transpiled — source.py
weather = "rainy"

if weather == "rainy":
    print("Take umbrella")
else:
    print("Stay home")

while counter <= 5:
    print(counter)
    counter = counter + 1

Why the verb comes last

Across the Eurasian steppe and into the Korean peninsula and Japan, a family of unrelated-by-descent but typologically related languages share two habits: they build meaning by stacking suffixes onto a fixed root, and they save the predicate for the end of the clause. You establish the subject, the object, the condition — then, finally, the action.

Most programming languages inherited the opposite order from English: if comes first, the condition follows. BOREALIS inverts that. The condition is stated plainly, and if is glued to the end of it as a bound suffix — the same structural position a Turkic conditional suffix like -se occupies on a verb stem.

Every rule in the grammar is anchored to the end of the line, so a line can only ever satisfy one rule. There's no ambiguity to resolve — the parser finds exactly one reading or none.

Get running

Two ways in: a standalone executable, or the Python package.

Download the executable

No Python required. Grab borealis.exe from the releases page and run it from a terminal.

borealis.exe run examples\hello.bor

Or install the package

If you already have Python 3.8+, clone the repo and install it as a command.

python -m pip install -e .
borealis run examples/hello.bor

Write your first .bor file

Copy examples/hello.bor, rename it, and change the logic. Any variable assignment or arithmetic line passes through unchanged.
